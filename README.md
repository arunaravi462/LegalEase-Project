# LegalEase – AI-Powered Legal Document Generator

A simple Streamlit project for generating editable legal document drafts from user-provided details.

## Features
- Multiple document types
- Party and agreement details form
- Document preview
- TXT download
- Simple and responsive Streamlit interface

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Demo
Deploy this repository on Streamlit Community Cloud to create a public demo URL.
